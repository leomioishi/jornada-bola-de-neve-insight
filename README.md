# Bola de Neve do Insight
## Visão Geral
- **Bola de Neve do Insight**: O PROCESSO (dinâmica temporal e dialética de acumulação e refinamento contínuo).
- **Montinho & Montão**: O MECANISMO DE CONSOLIDAÇÃO (arquitetura de registro e síntese atômica e cumulativa).
## O Fluxo Linear
`INSIGHT → CONVERSA → MICROCONSOLIDAÇÃO → NOVO INSIGHT → NOVA CONVERSA → NOVA CONSOLIDAÇÃO → CONSOLIDAÇÃO CANÔNICA`
## Estrutura do Repositório
- `01-montinhos/`: Consolidações atômicas de microassuntos (foco unitemático, alta densidade).
